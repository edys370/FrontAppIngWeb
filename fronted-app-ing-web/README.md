## 🚀 Ejecución en Desarrollo

```bash
npm install
npm run dev
```

La aplicación estará disponible en `http://localhost:5173`.

### Variables de Entorno (`.env`)
```env
VITE_API_URL=http://localhost:3001
VITE_APP_NAME="Products Microservice"
```
